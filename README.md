# PRIXVILLE. The Ledger

A KOL page that lines the post up with the wallet.

Sample dossiers only. No live keys. No real people's trades.

## What it checks

- A mention, then the buy and the sell on wallets tied to that handle.
- Wallet labels stay separate: signed, self-linked, funded by a linked wallet, payout sheet, shared funder, rumor.
- A lone rumor is listed. It does not move the grade.
- X crowd likability is a second ballot. One account, one vote. Not weighted by followers.
- Alerts fire when the clock flips: bought then posted, or posted then sold.

## Run

Open `index.html`. No build step.
